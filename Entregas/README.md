# Entregas

Onde o time coloca trabalho em andamento e artefatos prontos para o usuário revisar.

Quando um especialista produz algo substancial — um brief de pesquisa, um documento em rascunho, uma análise de contratação, um plano multi-arquivo — ele chega aqui, não na Wiki pessoal. Entregas é a superfície de trabalho do time: com timestamp, frequentemente organizado por data, frequentemente criado e descartado entre sessões.

## Quando usar

- **Pax** entrega um relatório de pesquisa → `Entregas/AAAA-MM-DD-<slug-topico>.md`
- **Nolan** entrega uma análise de contratação → `Entregas/AAAA-MM-DD-<slug-papel>-pesquisa-contratacao.md`
- Um novo especialista entrega um projeto multi-arquivo → `Entregas/AAAA-MM-DD-<slug-projeto>/`
- **Larry** reúne briefs de múltiplos especialistas para uma iniciativa → uma pasta por iniciativa, nomeada por data e slug

## Quando NÃO usar

- Fatos pessoais (pessoas, projetos, metas, hábitos) → `Wiki pessoal/`
- Entradas de diário diário → `Wiki pessoal/Diário/`
- Material de referência que o time precisa para sempre (SOPs, Fluxos de Trabalho, Diretrizes) → `Wiki equipe/`

Convenção de nomenclatura: veja `Wiki equipe/Diretrizes/DI-001-convencoes-de-nomeacao.md`.
