# Bem-vinda ao sistema de tarefas da WeWiki

## O que é isto

Esta é uma tarefa de exemplo que vem com o WeWiki da WeWiki. Ela demonstra o formato de tarefa canônico: como o frontmatter se parece quando está corretamente preenchido, como os arrays de referências cruzadas devem ser preenchidos, e como as seções do corpo devem ser estruturadas.

Leia esta tarefa. Depois assuma-a via [[SOP-assumir-tarefa]], percorra os passos de encerramento via [[SOP-fechar-tarefa]], e escreva uma entrada de diário curta via [[SOP-escrever-entrada-diario]] se aprender algo durável ao longo do caminho.

Este é o loop de tarefas completo: criar → assumir → trabalhar → fechar → (se durável) escrever no diário.

## Contexto a um clique

- Assumir: [[SOP-assumir-tarefa]]
- Fechar: [[SOP-fechar-tarefa]]
- Se aprender algo durável: [[SOP-escrever-entrada-diario]]
- Regras de nomenclatura: [[DI-001-convencoes-de-nomeacao]]
- Regras de frontmatter: [[DI-002-convencoes-de-frontmatter]]

## Critérios de sucesso

- Você percorreu o loop de tarefas completo (assumir, trabalhar, fechar) pelo menos uma vez.
- O `INDEX.md` foi reconstruído automaticamente pelos SOPs que você executou.
- Você entende como o sistema de referências cruzadas da tarefa conecta SOPs, logs de sessão e entradas de diário.
